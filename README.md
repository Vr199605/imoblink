# ImobLink — Catálogo Digital para Corretores Autônomos

Sistema web moderno (Mobile-First) para corretores de imóveis autônomos gerenciarem e apresentarem seus imóveis com alto padrão, links rápidos para WhatsApp e lâminas em PDF em 1 clique.

## 🚀 Como Rodar Localmente

1. Instale as dependências:
```bash
npm install
```

2. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no seu navegador.

## 📦 Deploy na Vercel (100% Gratuito)

Este projeto foi construído sobre Next.js e é 100% compatível com a infraestrutura gratuita da Vercel (Zero Config).
